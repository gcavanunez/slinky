Extend TUI navigation: full-page (`ctrl-f`/`ctrl-b`) and line-wise (`ctrl-e`/`ctrl-y`) scrolling, in-document search from the document pane (`/` with `n`/`N` match jumping), markdown heading jumps (`{`/`}`), and mouse support — click rows, panels, and catalog tabs; wheel-scroll lists and the file tree.
